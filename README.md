# Face Detection using Haar Cascade

A Python-based face detection application using OpenCV's Haar Cascade Classifier. The project provides both a command-line implementation and a graphical user interface built with Tkinter.

The application can detect faces in real time using a webcam or detect faces from an image file.

## Features

- Real-time face detection using webcam
- Face detection from image files
- Multiple face detection
- Face count display
- Bounding boxes around detected faces
- Haar Cascade face detection
- Tkinter graphical user interface
- Upload images through GUI
- Save processed detection results
- Different detection settings for webcam and images

## Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- Tkinter
- Pillow
